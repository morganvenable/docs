Every Svalboard uses USB vendor ID <code>{stable.vid}</code>.
The product ID depends on the firmware release and on the firmware flashed to each half.
These tables are generated from the firmware source, so they match the release files.

## Linux udev rule

On Linux, Keybard needs a udev rule to open the board. One rule covers every product ID above. See [Linux: the udev rule](/firmware/linux-udev/).
