import facts from '../../../data/facts.json';

export const stable = facts.firmware.stable;
export const next = facts.firmware.next;
export const pid = (side) => (side ? <code>{side.pid}</code> : '—');
export const label = (m) => (m.deprecated ? `${m.label} (deprecated)` : m.label);

Every Svalboard uses USB vendor ID <code>{stable.vid}</code>.
The product ID depends on the firmware release and on the firmware flashed to each half.
These tables are generated from the firmware source, so they match the release files.

{/* VERIFY: Confirm the board reports the product ID of the half connected to USB, so a page can say which ID a computer sees. */}

## Current release

<code>{stable.tag}</code>, released {stable.date}.{stable.singleImage ? ' Every module uses the same product IDs.' : ' Each pointing module has its own firmware, with its own product IDs.'}

			<tr><td>{label(m)}</td><td>{pid(m.left)}</td><td>{pid(m.right)}</td></tr>

## Linux udev rule

On Linux, Keybard needs a udev rule to open the board. One rule covers every product ID above. See [Linux: the udev rule](/firmware/linux-udev/).

See [Releases](/reference/releases/) for the firmware files in each release.
